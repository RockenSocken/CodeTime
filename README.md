# CodeTime-Watchface
A code-inspired Pebble watchface displaying time, date, weather, battery, and step count. Designed for high-contrast readability with configurable 12/24-hour format and Celsius/Fahrenheit units, plus automatic location-based weather updates.

Developed from 04/01/2026 to 05/04/2026 with help from Claude.ai and ChatGPT. Primarily designed for the original Pebble Time, but also compatible with Pebble Classic, Steel, Pebble 2, and Pebble 2 Duo.

Feel free to use the code and make improvements if you want—just please give me a shoutout if you make a better version :p
